# Orbit System (UI Core)

## Concept
A central orbit UI that acts as the entry point of the experience.

## Initial State
- Orbit positioned at center
- Background visible
- No main card shown

## Interaction
On click:
1. Orbit animates to the left
2. Main card appears on the right

## Constraints
- Smooth animation
- No collision between orbit elements
- Maintain visual balance

## Future Expansion
- Multiple nodes
- Dynamic transitions
