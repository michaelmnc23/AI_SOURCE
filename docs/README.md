# AI Source of Truth

This repository is the single source of truth for all product, UI, and technical decisions.

## Rules
1. All finalized ideas must be written into `/docs`
2. All implementation must reference a doc
3. No assumptions outside documented specs

## Structure
- /product → vision, flows
- /ui → UI systems and behaviors
- /tech → architecture and conventions

This repo is designed to be read by both humans and AI (ChatGPT + Codex).
